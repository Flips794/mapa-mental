# Mapa Mental

Aplicativo de mapa mental **100% offline**, em um único arquivo HTML. Sem login, sem servidor, sem mensalidade — abre direto no navegador e salva sozinho no seu computador.

## ✨ Funcionalidades

- 🧠 Mapa mental com nó central e ramos ilimitados, ligados por conectores curvos
- 🔽 Recolher / expandir ramos (mostra quantos itens ficam escondidos)
- 🎨 10 cores para os blocos
- 📝 Anotações longas em cada nó
- 🖼️ Anexar imagens (miniatura + ampliar ao clicar)
- 📎 Anexar documentos (baixar com um clique)
- 💾 Salvamento automático no navegador (IndexedDB, com fallback para localStorage)
- ⬇️ Exportar / ⬆️ Importar backup em `.json`
- 🔍 Busca por texto nos nós e nas anotações
- 🖱️ Arrastar o fundo para navegar; `Ctrl +` / `Ctrl −` para zoom

## 🚀 Como usar

1. Acesse https://flips794.github.io/mapa-mental/ ou abra o arquivo `index.html` no navegador (dois cliques).
2. Clique num nó para selecioná-lo e edite pelo painel da direita (cor, anotação, anexos).
3. Botão **+** no nó (ou tecla **Tab**) cria um sub-tópico; **Enter** cria um nó irmão.
4. Use **Exportar backup** de vez em quando para guardar uma cópia `.json` onde quiser.

> 🌐 Publicado via GitHub Pages: https://flips794.github.io/mapa-mental/

## 🛠️ Tecnologia

HTML, CSS e JavaScript puro (vanilla), sem dependências externas. Tudo roda no navegador do usuário — nada é enviado para a internet.
